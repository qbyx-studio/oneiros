# Dance

Dance produces video and audio. Ask only for missing shot, motion, duration,
aspect, sound, or reference choices required by the live workflow schema.

Auto may recommend a Fast Proxy or Same-Model Draft. Disclose that a proxy made
with a different model can drift from the final. Guided retains the user's
workflow choice. Manual retains exact supported controls. Experimental routes
must be labeled using live catalogue metadata.

Keep prompts limited to the shot being rendered. Put later cuts, CTA plans, and
delivery notes in the production brief. Preserve original Takes and separate
editable audio or assembly assets. Do not describe diffusion generation as live
streaming or call a draft final.

## HyperFrames handoff

Treat the local HyperFrames CLI and `hyperframes` Skill as an optional editing
companion to Dance.
Check their availability quietly while preparing video work. A missing local
HyperFrames install must not block Oneiros; mention it only when editing is
requested or offered. The separate hosted HeyGen MCP is optional and must never
be assumed authenticated or required.

After the first verified video, ask one concise question: revise the Oneiros
generation, accept it, or continue into a HyperFrames edit. On an editing choice,
pass the verified artifact and production brief to `hyperframes`, preserve the
source, and create or resume its draft in the same production folder. Offer the
development preview before a new final render; do not start a server or render
until the user chooses that path.

# Dream

Dream produces images. Ask only for missing composition, dimensions, seed, or
reference choices required by the live workflow schema. Do not ask for video
duration or soundtrack.

Auto chooses a compatible installed image route. Guided compares real engines
when several exist, or meaningful composition/settings choices when only one
exists. Manual retains the exact supported workflow and controls. Never claim
an attached image conditioned generation unless the selected schema accepts it.

Review the actual pixels, preserve originals, and use deterministic compositing
for pixel-exact logos, UI, CTA text, and legal copy when available.
